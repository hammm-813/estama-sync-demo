# 予約サイト × エステ魂 出勤取り込み（デモ）

予約サイトと管理画面に「エステ魂の出勤表を読み込んで反映する」機能を付けたデモです。
店舗・セラピスト・電話番号はすべて架空です。問題がなければ本番のサイトに同じ変更を入れる予定です。

- 予約サイト: `index.html`
- 管理画面: `admin/`
- エステ魂の読み込み: `estama.js`（サーバー側）

## 見た目だけ確認する（GitHub Pages）

GitHub Pages の URL で画面を見られます。サーバーがないので、予約は送信されず、エステ魂の取り込みも動きません。

## エステ魂の取り込みを試す（パソコンで動かす）

Node.js 18 以上が必要です。追加のインストールはいりません。

```bash
git clone https://github.com/hammm-813/estama-sync-demo.git
cd estama-sync-demo
node server.js
```

1. http://localhost:8793/admin/ を開く（管理画面は、動かしているパソコンからしか開けません）
2. 「エステ魂」タブで、エステ魂の店舗ログイン用メールアドレスとパスワードを入れて「保存して今すぐ取り込む」
3. 「出勤」タブと予約サイト（http://localhost:8793/）に、エステ魂の出勤が反映されていることを確認

## 取り込みのしくみ

- エステ魂は**読むだけ**です。エステ魂の内容は変更しません。
- 読むのは今日から14日分の出勤表（「出勤表」ページの1日表示）です。
- `node server.js` が動いている間、10分ごとに自動で取り込みます（タブでオン・オフできます）。
- エステ魂の ○ は予約できる時間、×・TEL は予約サイトで選べない時間になります。全部 × の日は満員扱いです。
- エステ魂のセラピストは、名前が同じ人と自動でつなぎます。いない人は、エステ魂の写真と年齢で新しく追加します。
- つながったセラピストの出勤はエステ魂の内容で上書きされ、管理画面では変更できません（変更はエステ魂側で）。
- このサイトで「確定」にした予約の時間は、取り込んだ後も × のままです。
- ログイン情報は `data/estama.json` にだけ保存されます（`.gitignore` 済みで GitHub には上がりません）。

## 見てほしいところ

- 取り込んだ出勤・空き状況が、エステ魂の出勤表と合っているか
- 管理画面「エステ魂」タブと「出勤」タブの表示・使い勝手
- エラーのとき（パスワード違いなど）の表示
